# Australian Retail Sales Dashboard

## Project Overview
An interactive Excel dashboard designed to analyse retail sales performance and present key business insights through visualisations.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel formulas

## Dashboard Features
- Total sales KPI
- Sales performance visualisations
- State-level sales analysis
- Product category filtering
- Interactive dashboard navigation

## Key Skills Demonstrated
- Data analysis
- Data visualisation
- Interactive dashboard development
- Business reporting
- Excel PivotTable analysis

## Project File
`Australian_Retail_Sales_Dashboard.xlsx`

## How to Use
1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Navigate to the Dashboard worksheet.
4. Use the category slicer to explore sales performance.
